## 3. Aufruf der Website (Hosting bei GitHub Pages) {#hosting}

Die Website liegt bei GitHub Pages, einem Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub gehört zur Microsoft Corporation.

**Welche Daten?** Damit Ihr Browser die Seiten anzeigen kann, übermittelt er bei jedem Aufruf automatisch Angaben an den Server: Ihre IP-Adresse, Datum und Uhrzeit, die angeforderte Seite oder Datei, die zuvor besuchte Seite (Referrer) sowie Typ und Version von Browser und Betriebssystem. **Speicherdauer:** Die Logs werden ausschließlich von GitHub gespeichert. Ich kann sie nicht einsehen und werte sie nicht aus. Wie lange GitHub sie aufbewahrt, legt GitHub fest.

## 4. Kontaktformular (Static Forms) {#kontaktformular}

**Welche Daten?** Was Sie in das Formular eintragen (Name, E-Mail-Adresse, Nachricht). Beim Absenden fallen zusätzlich technische Angaben an, etwa IP-Adresse, Browserkennung und die Seite, von der das Formular abgeschickt wurde.

**Wozu?** Ausschließlich, um Ihre Nachricht zu lesen und zu beantworten.

**Rechtsgrundlage:** Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse liegt darin, Anfragen beantworten zu können.

**Wer ist beteiligt?** Das Formular wird über den Dienst Static Forms (Betreiber: Qualascend) abgewickelt. Static Forms nimmt die Eingaben entgegen und schickt sie mir per E-Mail. Static Forms handelt dabei in meinem Auftrag; ein Vertrag zur Auftragsverarbeitung nach Art. 28 DSGVO ist Teil der Nutzungsbedingungen des Dienstes.

**Wo und wie lange?**

- Ihre Formulareingaben werden in einem Rechenzentrum von Amazon Web Services in Frankfurt am Main gespeichert und dort nach 30 Tagen automatisch gelöscht.
- Static Forms selbst läuft auf Servern in den USA (Anbieter: Vercel, Inc.). Technische Protokolle der Übermittlung, also IP-Adresse, Browserkennung, Herkunftsseite, Feldnamen und Zustellstatus, aber nicht der Inhalt Ihrer Nachricht, werden in den USA gespeichert und laut Static Forms spätestens nach einem Jahr gelöscht.
- Die Benachrichtigungs-E-Mail mit Ihrer Nachricht wird über Amazon Web Services in den USA an mich versendet.
- Zur Spam-Erkennung prüft der Dienst CleanTalk die Eingaben; diese Prüfung findet in der EU statt.

**USA:** Für die Übermittlung in die USA gelten die Standardvertragsklauseln der EU-Kommission (Art. 46 Abs. 2 lit. c DSGVO), die Teil des Auftragsverarbeitungsvertrags von Static Forms sind. Einige der von Static Forms eingesetzten Dienstleister sind zusätzlich nach dem EU-US Data Privacy Framework zertifiziert.

**Bei mir:** Sobald Ihr Anliegen erledigt ist, lösche ich die Nachricht aus meinem Postfach.

Mehr dazu: [Datenschutzhinweise von Static Forms](https://www.staticforms.dev/privacy-policy) · [Auftragsverarbeitungsvertrag](https://www.staticforms.dev/dpa)

Oben rechts auf jeder Seite gibt es einen Schalter für helles und dunkles Design. Nur wenn Sie ihn anklicken, merkt sich Ihr Browser Ihre Wahl im sogenannten Local Storage, damit die Seite beim nächsten Besuch wieder so aussieht. Gespeichert wird lediglich das Wort „light“ oder „dark“. Diese Angabe bleibt auf Ihrem Gerät und wird weder an mich noch an andere übertragen.

Ihre Einwilligung ist dafür nicht nötig: Nach § 25 Abs. 2 Nr. 2 TDDDG darf eine Website Informationen auf Ihrem Gerät ablegen, wenn das für eine Funktion, die Sie ausdrücklich nutzen möchten, unbedingt erforderlich ist. Sie können den Eintrag jederzeit in den Einstellungen Ihres Browsers entfernen, indem Sie die gespeicherten Daten dieser Website löschen.
